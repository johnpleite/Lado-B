# Project Guidelines

## Code quality
- Write clear, straightforward code that is easy for human developers to read and maintain.
- Avoid duplicating logic; search for existing implementations and reuse or improve them before adding another. Keep abstractions simple and focused.
- Prefer descriptive names and explicit control flow over clever or overly compact code.

## Project style
- Use `src/theme/colors.ts` as the source of the project's color palette and `src/theme/theme.tsx` for theme behavior and styling conventions. Prefer theme colors over hard-coded colors.
- `assets/images/icon.png` is the primary project icon; use it as the reference for the app's visual identity.

## Git
- Do not create or amend commits unless a developer explicitly authorizes the commit.
